# Backend experimental — no desplegar a producción

Este directorio contiene una función callable de Firebase para otorgar 500 BC + 5 BCR al registrar una cuenta, y 1000 BC + 10 BCR al verificar el correo. La función obtiene la identidad mediante Admin SDK, usa la UID autenticada y consulta el estado real de verificación; no recibe cantidades ni saldo del cliente. La transacción registra las concesiones una sola vez. El saldo resultante vive en `rpbSecure/users/{uid}`, separado del perfil legacy que todavía permite guardado desde el cliente. **No se suma al saldo visible del juego hasta migrar su economía.**

`domain.cjs` contiene además la lógica propuesta de MMR Elo por equipos (K=32, inicial 1000, 7 rangos y divisiones); requiere un resultado aprobado por un árbitro de servidor. No existe endpoint cliente de liquidación Ranked. El algoritmo no admite bots ni duplicados, y no modifica MMR en casual. No constituye un sistema anti-cheat completo.

Los archivos firebase.emulator.json y database.emulator.rules.json son exclusivos de un proyecto demo. No reemplazan reglas existentes. Instalación de dependencias y prueba de emuladores pendientes; no se ejecutó Firebase Admin en este entorno. Para el proyecto demo usar `firebase emulators:start --project demo-rpb-alpha035 --config firebase.emulator.json` desde este directorio tras instalar dependencias con npm y disponer de Firebase CLI. No ejecutar firebase deploy.

Antes de cualquier lanzamiento: migración y conciliación de inventarios, reemplazo de api.save para campos protegidos, reglas completas, transacciones concurrentes y pruebas de emulador, resultados de partidas autoritativos, política de cuentas existentes y costes/plan de Firebase. Los saldos de invitado son manipulables y no deben importarse directamente a una economía competitiva. La transferencia debe distinguir progreso cosmético/local de recompensas verificadas. La configuración de correo de Firebase queda pendiente. El modelo permite reclamar una vez a cualquier cuenta elegible, incluso existente; decidir si se limita a cuentas nuevas antes de producción.
